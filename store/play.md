## Name

Bol

## Short description

Speak Hindi or Hinglish. Bol types the cleaned text.

## Full description

Bol is a dictation app for Hindi, Hinglish, and English.

Hold a short line, including English words inside Hindi. Bol sends the recording to Sarvam Saaras and shows text you can edit. The Android keyboard can record in the app you were typing in and insert the result.

The recording is not kept after the request. Bol does not ask for a background microphone.

## Target API

Target Android API 36. The microphone permission is foreground only: `android.permission.RECORD_AUDIO`.

## Data safety

Audio is collected, sent to the developer’s server and then to Sarvam, and not stored. It is not used for advertising or tracking. See [privacy.md](privacy.md).
